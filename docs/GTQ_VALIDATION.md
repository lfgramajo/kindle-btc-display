# GTQ vendor validation

CoinGecko's official API changelog explicitly lists Guatemala (`GTQ`) among newly supported currencies. The v1.7.0 runtime uses CoinGecko's `vs_currencies` parameter for arbitrary supported secondary fiat codes, so GTQ follows the same path as EUR, GBP, JPY, and other non-MXN secondary fiat selections.

Official reference: https://docs.coingecko.com/changelog/10122018

This note is public documentation only; it does not contain runtime or private-environment data.
